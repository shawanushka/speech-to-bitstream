Theory

What is ASCII, and why does data communication need it?

Computers and wires only carry bits. Two machines can swap text only if they agree which bit pattern means which character. ASCII is that agreement.

Definition

ASCII is the American Standard Code for Information Interchange. It assigns a number from 0 to 127 to 128 characters: letters, digits, punctuation and control signals. Each number is written as a 7-bit binary value. In a byte the 8th bit is left as 0, used for parity, or used by extended character sets.

One character, three forms

'A' → 65 → 1000001

Character, decimal code, 7-bit binary. The transmitter sends only the bits. The receiver looks the code up in the same table.

    Anatomy of the 128 codes

    The set is laid out in blocks, and the layout has useful patterns.

    Case is one bit

    A 1000001
    a 1100001

    Upper and lower case differ only in bit 5 (value 32). Add 32 to get lowercase.

    Digits sit at 0x30

    '7' = 0x30 + 7 = 55

    Subtract 48 from a digit's code to get its numeric value.

    Control codes carry protocol

    LF 10 · CR 13 · ACK 6

    Codes 0 to 31 were made for teleprinters and links: line feed, acknowledge, end of transmission.

    Encoding

    From bits to a signal on the wire

    Bits are numbers. A wire carries voltage. Line coding is the rule that turns one into the other, and parity and framing make the stream safe to receive.

    Line coding, five ways

    Type a word. The same bits are drawn with each scheme. Levels: top is positive, middle is zero, bottom is negative.

    SchemeRuleStrengthWeakness

    Parity, the simplest error check

    A parity bit makes the count of 1s even (or odd). Click any bit to flip it, as noise would, and see what the receiver notices.

    Framing a character for a serial line (UART)

    The line idles high. A start bit (0) wakes the receiver, data bits follow least significant bit first, and a stop bit (1) returns the line to idle.
